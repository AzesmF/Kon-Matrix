# ROADMAP — План развития KON-MATRIX

**Версия:** 1.1 (актуализирован 2026-05-07)  
**Статус:** активная разработка

---

## Этап 1: Фундамент (месяцы 1-3) — выполнен

| Месяц | Задача | Результат |
|---|---|---|
| 1-2 | Публикация репозитория с ядром методологии, примерами адаптации, лицензией и контактами | Репозиторий на GitHub, документация, примеры |
| 2-3 | Ребрендинг текстов, перевод на деловой язык, унификация терминологии | Выполнено (май 2026) |

---

## Этап 2: Текущие задачи (месяцы 3-4)

- **Доработка визуала:** создание логотипа, схемы 4x3, иконок для принципов.
- **Запуск пилотного аудита:** самооценка данного репозитория по своей же методологии (пример «Аудит GitHub-репозитория»).
- **Разработка авто-сканера на Python (MVP):** проверка базовых критериев уровня L1.

---

## Этап 3: Инструментарий (месяцы 4-8)

| Месяц | Задача | Результат |
|---|---|---|
| 4-5 | Разработка авто-сканера (CLI) | Скрипт, проверяющий INT-L1, PUR-L1, EVO-L1, TRA-L1 для git-репозиториев |
| 6 | Интеграция с GitHub Actions | Автоматическая проверка репозиториев при PR |
| 7 | Шаблоны отчётов (PDF/HTML) | Формализованные заключения аудита по матрице |
| 8 | Бета-тестирование | 3+ пилотных проекта используют сканер |

---

## Этап 4: Экосистема (месяцы 9-12)

| Месяц | Задача | Результат |
|---|---|---|
| 9-10 | Веб-приложение для визуальной оценки | Дашборд с уровнем зрелости |
| 11 | Партнёрская программа | Обучение консультантов |
| 12 | Стандарт RFC | Публикация версии 1.0 методологии как открытого стандарта |
