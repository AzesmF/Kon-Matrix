## Проблема

Большинство методологий оценки жёстко привязаны к конкретному домену. ИТ-аудит не работает для HR, производственная оценка не подходит для AI-систем. Нужен единый ствол, из которого растут любые ветви.

## Решение: Матрица Конов

**12 ячеек — 4 Принципа × 3 Уровня зрелости.**

Каждая ячейка содержит измеримый критерий, требуемое доказательство и метод верификации.

Четыре Кон:
- 🔒 **Целостности** — артефакты неизменны и проверяемы
- 🧼 **Чистоты** — система не содержит скрытых агентов
- 🌱 **Становления** — эволюция без принудительной фиксации
- 👁️ **Прозрачности** — полная наблюдаемость состояний и решений

## Быстрый старт

1. Прочитать [matrix-core.md](./docs/matrix-core.md) — полная таблица всех 12 ячеек
