# Пример адаптации: Веб-студия / Разработка сайтов

**Ветвь от Ствола KON-MATRIX v2.0**

Этот документ показывает, как универсальные критерии Матрицы Конов применяются к процессу веб-разработки.

---

## Какие артефакты собирать

| Кон | Уровень | Артефакт для веб-студии |
|---|---|---|
| INT | L1 | `asset_hashes.json` в корне репозитория — контрольные суммы CSS/JS бандлов каждого релиза |
| INT | L2 | Git-репозиторий без force push; история коммитов линейна |
| INT | L3 | Хеш-суммы бандлов, проверенные на CDN/сервере после деплоя |
| PUR | L1 | `package.json` + `yarn.lock` / `package-lock.json` с полным списком зависимостей; диаграмма API-интеграций |
| PUR | L2 | Отчёт `npm audit` или `yarn audit` в CI/CD без уязвимостей High/Critical |
| PUR | L3 | Протокол пентеста; отчёт о проверке на утечки данных через сторонние скрипты |
| EVO | L1 | `CHANGELOG.md` с датами и описанием обновлений |
| EVO | L2 | Папка `docs/adr/` с файлом, обосновывающим выбор CMS/фреймворка |
| EVO | L3 | Демонстрация обратной совместимости API при мажорном обновлении |
| TRA | L1 | Логи сервера в формате с trace_id для каждого запроса |
| TRA | L2 | Статус-страница (например, status.example.com) с метриками аптайма |
| TRA | L3 | Личный кабинет клиента с функцией «Экспорт моих данных» |

---

## Как интерпретировать критерии

- **INT-L1:** После каждой сборки CI/CD генерирует `asset_hashes.json`, который коммитится в репозиторий.
- **PUR-L2:** `npm audit` встроен в пайплайн; при обнаружении High/Critical — билд падает.
- **EVO-L2:** При выборе нового фреймворка разработчик создаёт ADR с обоснованием и указанием отвергнутых альтернатив.

---

## Ожидаемый отчёт

При полном прохождении Матрицы для веб-студии формируется отчёт:

| Кон | L1 | L2 | L3 |
|---|---|---|---|
| Целостность | ✅ `asset_hashes.json` присутствует | ✅ Git-история без перезаписи | ✅ Хеши на проде совпадают с CI/CD |
| Чистота | ✅ `package.json` и диаграмма API | ✅ `npm audit` чист | ✅ Пентест пройден |
| Становление | ✅ `CHANGELOG.md` в наличии | ✅ ADR присутствует | ✅ Обратная совместимость подтверждена |
| Прозрачность | ✅ Логи структурированы | ✅ Статус-страница работает | ✅ Экспорт данных клиента функционирует |
