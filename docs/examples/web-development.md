# Пример адаптации: Веб-студия / Разработка сайтов

**Ветвь от ствола KON-MATRIX v2.0**

Этот документ показывает, как универсальные критерии матрицы применяются к процессу веб-разработки.

---

## Какие проверяемые объекты собирать

| Принцип | Уровень | Проверяемый объект для веб-студии |
|---|---|---|
| Целостность | L1 | `asset_hashes.json` в корне репозитория — контрольные суммы CSS/JS бандлов каждого релиза |
| Целостность | L2 | Git-репозиторий без force push; история коммитов линейна |
| Целостность | L3 | Хеш-суммы бандлов, проверенные на CDN/сервере после деплоя |
| Чистота | L1 | `package.json` + `yarn.lock` / `package-lock.json` с полным списком зависимостей; диаграмма API-интеграций |
| Чистота | L2 | Отчёт `npm audit` или `yarn audit` в CI/CD без уязвимостей High/Critical |
| Чистота | L3 | Протокол пентеста; отчёт о проверке на утечки данных через сторонние скрипты |
| Развитие | L1 | `CHANGELOG.md` с датами и описанием обновлений |
| Развитие | L2 | Папка `docs/adr/` с файлом, обосновывающим выбор CMS/фреймворка |
| Развитие | L3 | Демонстрация обратной совместимости API при мажорном обновлении |
| Прозрачность | L1 | Логи сервера в формате с trace_id для каждого запроса |
| Прозрачность | L2 | Статус-страница (например, status.example.com) с метриками аптайма |
| Прозрачность | L3 | Личный кабинет клиента с функцией «Экспорт моих данных» |

---

## Как интерпретировать критерии

- **Целостность L1:** После каждой сборки CI/CD генерирует `asset_hashes.json`, который коммитится в репозиторий.
- **Чистота L2:** `npm audit` встроен в пайплайн; при обнаружении High/Critical — билд падает.
- **Развитие L2:** При выборе нового фреймворка разработчик создаёт ADR с обоснованием и указанием отвергнутых альтернатив.

---

## Ожидаемый отчёт

При полном прохождении матрицы для веб-студии формируется отчёт:

| Принцип | L1 | L2 | L3 |
|---|---|---|---|
| Целостность | ✅ `asset_hashes.json` присутствует | ✅ Git-история без перезаписи | ✅ Хеши на проде совпадают с CI/CD |
| Чистота | ✅ `package.json` и диаграмма API | ✅ `npm audit` чист | ✅ Пентест пройден |
| Развитие | ✅ `CHANGELOG.md` в наличии | ✅ ADR присутствует | ✅ Обратная совместимость подтверждена |
| Прозрачность | ✅ Логи структурированы | ✅ Статус-страница работает | ✅ Экспорт данных клиента функционирует |
