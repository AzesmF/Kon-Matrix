# Пример адаптации: Производство и офлайн-бизнес

**Ветвь от ствола KON-MATRIX v2.0**

Этот документ показывает, как универсальные критерии матрицы применяются к производственным, логистическим и иным офлайн-процессам.

---

## Какие проверяемые объекты собирать

| Принцип | Уровень | Проверяемый объект для офлайн-бизнеса |
|---|---|---|
| Целостность | L1 | Фотография входного сырья / партии с отметкой времени; журнал приёмки с подписью |
| Целостность | L2 | Журнал изменений регламентов (Google Docs с историей версий, без возможности удаления); логи датчиков с цифровой подписью |
| Целостность | L3 | Сквозная цепочка: фото сырья → запись в ERP → контрольные суммы данных датчиков → акт приёмки готовой продукции |
| Чистота | L1 | Манифест оборудования и сырья: список единиц техники, источников сырья, паспорта качества |
| Чистота | L2 | Отчёт о проверке на отсутствие недокументированных примесей (лабораторный анализ сырья); калибровка датчиков |
| Чистота | L3 | Независимый аудит производства на отсутствие скрытых операций (видеонаблюдение с аналитикой, контроль целостности записи) |
| Развитие | L1 | Журнал изменений регламентов (версионность, даты, причины) |
| Развитие | L2 | Протоколы планёрок / ретроспектив с разделом «Рассмотренные альтернативные технологии» |
| Развитие | L3 | Демонстрация бесшовного перехода на новую линию без остановки выпуска (миграция на параллельном конвейере) |
| Прозрачность | L1 | Логи датчиков с временной меткой, идентификатором смены и описанием события |
| Прозрачность | L2 | Дашборд начальника цеха с загрузкой линий, метриками качества и статусом заказов в реальном времени |
| Прозрачность | L3 | Полный аудиторский след по партии: от поступления сырья до отгрузки клиенту, включая всех исполнителей и операции |

---

## Как интерпретировать критерии

- **Целостность L1:** При приёмке сырья кладовщик делает фото с автоматической отметкой времени (например, через Telegram-бота), которое сохраняется в неизменяемом облаке.
- **Чистота L2:** Лаборатория ежеквартально проверяет образцы на соответствие заявленному составу; результаты публикуются для заказчиков.
- **Развитие L2:** Перед внедрением нового станка фиксируются рассмотренные альтернативы (другие модели, их плюсы/минусы) в протоколе технического совета.
- **Прозрачность L3:** Клиент может запросить полный аудиторский след по своей партии — от сырья до отгрузки.

---

## Ожидаемый отчёт

| Принцип | L1 | L2 | L3 |
|---|---|---|---|
| Целостность | ✅ Фото и журнал приёмки | ✅ История регламентов неизменна | ✅ Сквозная цепочка подтверждена |
| Чистота | ✅ Манифест оборудования | ✅ Лабораторный анализ чист | ✅ Независимый аудит пройден |
| Развитие | ✅ Журнал изменений регламентов | ✅ Альтернативы зафиксированы | ✅ Бесшовная миграция на новую линию |
| Прозрачность | ✅ Логи датчиков структурированы | ✅ Дашборд в реальном времени | ✅ Полный аудит по партии |

---

> Физические процессы также могут быть прозрачными, целостными и эволюционными при правильном сборе артефактов.
