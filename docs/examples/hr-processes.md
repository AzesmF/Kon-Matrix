# Пример адаптации: Команда / HR-процессы

**Ветвь от Ствола KON-MATRIX v2.0**

Этот документ показывает, как универсальные критерии Матрицы Конов применяются к управлению командой, оценке персонала и HR-процессам.

---

## Какие артефакты собирать

| Кон | Уровень | Артефакт для HR и команд |
|---|---|---|
| INT | L1 | Зафиксированные должностные инструкции и KPI с датами утверждения |
| INT | L2 | История изменений должностных инструкций и KPI в Google Docs с включённой историей версий, без возможности удаления |
| INT | L3 | Сквозная верифицируемость: от объявления вакансии до онбординга — все этапы подписаны, хешированы и архивированы |
| PUR | L1 | Манифест компетенций команды: файл `TEAM.md` с указанием, кто за что отвечает |
| PUR | L2 | Отчёт о проверке на отсутствие скрытых конфликтов интересов (декларации, реестр аффилированностей) |
| PUR | L3 | Независимый HR-аудит на предмет скрытой дискриминации и неформальных иерархий |
| EVO | L1 | Журнал изменений в структуре команды: когда и почему произошли переходы, повышения, найм |
| EVO | L2 | Протоколы ретроспектив и карьерных бесед с разделом «Рассмотренные альтернативные роли» |
| EVO | L3 | Демонстрация бесшовной ротации кадров: сотрудник переходит на новую роль без потери накопленного контекста |
| TRA | L1 | Все ключевые решения по персоналу фиксируются с датой, причиной и подписью |
| TRA | L2 | Каждый сотрудник имеет доступ к дашборду с текущими финансовыми метриками компании и статусом стратегических инициатив |
| TRA | L3 | Функция «Экспорт моего трека»: сотрудник в один клик получает всю историю своей работы, повышений, KPI и обратной связи |

---

## Как интерпретировать критерии

- **INT-L1:** Должностные инструкции и KPI хранятся в общей папке с датами утверждения; любое изменение — через pull request или предложение в Google Docs.
- **PUR-L1:** Файл `TEAM.md` лежит в корне корпоративного репозитория; каждый сотрудник имеет право внести предложение по его уточнению.
- **EVO-L2:** После каждой ретроспективы фиксируются не только принятые решения, но и отвергнутые варианты развития команды.
- **TRA-L2:** Дашборд с метриками компании прозрачен для всех сотрудников — от стажёра до директора.
