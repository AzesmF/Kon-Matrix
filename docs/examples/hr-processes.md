# Пример адаптации: Команда / HR-процессы

**Ветвь от ствола KON-MATRIX v2.0**

Этот документ показывает, как универсальные критерии матрицы применяются к управлению командой, оценке персонала и HR-процессам.

---

## Какие проверяемые объекты собирать

| Принцип | Уровень | Проверяемый объект для HR и команд |
|---|---|---|
| Целостность | L1 | Зафиксированные должностные инструкции и KPI с датами утверждения |
| Целостность | L2 | История изменений должностных инструкций и KPI в Google Docs с включённой историей версий, без возможности удаления |
| Целостность | L3 | Сквозная верифицируемость: от объявления вакансии до онбординга — все этапы подписаны, хешированы и архивированы |
| Чистота | L1 | Манифест компетенций команды: файл `TEAM.md` с указанием, кто за что отвечает |
| Чистота | L2 | Отчёт о проверке на отсутствие скрытых конфликтов интересов (декларации, реестр аффилированностей) |
| Чистота | L3 | Независимый HR-аудит на предмет скрытой дискриминации и неформальных иерархий |
| Развитие | L1 | Журнал изменений в структуре команды: когда и почему произошли переходы, повышения, найм |
| Развитие | L2 | Протоколы ретроспектив и карьерных бесед с разделом «Рассмотренные альтернативные роли» |
| Развитие | L3 | Демонстрация бесшовной ротации кадров: сотрудник переходит на новую роль без потери накопленного контекста |
| Прозрачность | L1 | Все ключевые решения по персоналу фиксируются с датой, причиной и подписью |
| Прозрачность | L2 | Каждый сотрудник имеет доступ к дашборду с текущими финансовыми метриками компании и статусом стратегических инициатив |
| Прозрачность | L3 | Функция «Экспорт моего трека»: сотрудник в один клик получает всю историю своей работы, повышений, KPI и обратной связи |

---

## Как интерпретировать критерии

- **Целостность L1:** Должностные инструкции и KPI хранятся в общей папке с датами утверждения; любое изменение — через pull request или предложение в Google Docs.
- **Чистота L1:** Файл `TEAM.md` лежит в корне корпоративного репозитория; каждый сотрудник имеет право внести предложение по его уточнению.
- **Развитие L2:** После каждой ретроспективы фиксируются не только принятые решения, но и отвергнутые варианты развития команды.
- **Прозрачность L2:** Дашборд с метриками компании прозрачен для всех сотрудников — от стажёра до директора.
