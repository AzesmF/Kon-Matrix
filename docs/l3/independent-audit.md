# Подготовка к независимому аудиту (KON-MATRIX L3)

Этот документ предназначен для внешних аудиторов и специалистов по безопасности, которые проверяют проект на соответствие методологии KON-MATRIX уровня L3.

## 1. Что проверяет аудитор

Аудитор должен убедиться, что проект закрыл все 12 ячеек матрицы (4 Кона × 3 уровня), с фокусом на L3.

### Целостность (INT-L3)
- **Артефакт:** `.slsa/provenance.json`
- **Проверка:** Запустить `python3 tools/verify-slsa.py --min-level 1`. Ожидается PASS.
- **Доказательство:** Ветка `master` защищена правилами (Branch Protection Rules), запрещены force-push, все коммиты подписаны.

### Чистота (PUR-L3)
- **Артефакт:** `sbom/sbom.cyclonedx.json`
- **Проверка:** Запустить `python3 tools/generate-sbom.py`. Убедиться, что SBOM актуален.
- **Проверка безопасности:** В GitHub Actions настроен OWASP ZAP DAST-скан (workflow `pur-l3-dast-scan.yml`). Отчёты доступны во вкладке Security.

### Развитие (EVO-L3)
- **Артефакт:** `docs/l3/zero-downtime-deployment.md`
- **Проверка:** Наличие runbook для Blue-Green / Canary деплоя.
- **Метрики:** MTTR < 5 мин (фиксируется в WORM-логах).

### Прозрачность (TRA-L3)
- **Артефакт:** `audit-logs/worm-chain.jsonl`
- **Проверка:** Запустить `python3 tools/worm-logger.py verify`. Ожидается валидность цепочки хешей.
- **Экспорт:** Запустить `python3 tools/export-audit-bundle.py`. Должен быть сформирован `manifest.json`.

## 2. Чек-лист аудитора

- [ ] Запущен `scanner-l3.py` → все 4 Кона PASS.
- [ ] Проверен `L3-PASSPORT.md` → все ссылки на артефакты активны.
- [ ] WORM-лог не имеет разрывов в цепочке хешей.
- [ ] SLSA-аттестат соответствует Level 1+.
- [ ] SBOM содержит все транзитивные зависимости.
