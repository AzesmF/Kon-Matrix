# Подготовка к ISO 27001:2022 через KON-MATRIX L3

KON-MATRIX L3 помогает закрыть технические контроли Annex A стандарта ISO 27001:2022.

## Маппинг на Annex A

### A.5: Организационные контроли
- **A.5.9 Управление активами:** KON-MATRIX PUR-L1 (документированный состав системы, SBOM).
- **A.5.35 Независимый аудит:** KON-MATRIX PUR-L3 (интеграция с внешними аудиторами, гайд `independent-audit.md`).

### A.8: Технологические контроли
- **A.8.24 Журналирование:** KON-MATRIX TRA-L1/L3 (структурированные логи, WORM).
- **A.8.25 Защита логов:** KON-MATRIX INT-L2 (подписанные коммиты, hash chain).
- **A.8.26 Мониторинг:** KON-MATRIX TRA-L2 (дашборды метрик).
- **A.8.32 Управление изменениями:** KON-MATRIX EVO-L2/L3 (ADR, SemVer, CI/CD).

## Statement of Applicability (SoA)

При формировании SoA для ISO 27001, используйте KON-MATRIX Passport как доказательство реализации технических контролей. Это сократит время аудита и снизит количество замечаний.

## Ограничения

KON-MATRIX фокусируется на технических и процессных аспектах разработки. Организационные контроли (A.5.1-A.5.34, кроме указанных) требуют отдельной проработки (политики ИБ, управление инцидентами, HR-процессы).
