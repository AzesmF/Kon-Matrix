# ADR-0001: Выбор Python для реализации L1-сканера

## Статус
Принято (2026-08-03)

## Контекст
Для реализации методологии Kon-Matrix требовался инструмент автоматической верификации репозиториев (L1-сканер). Необходимо было выбрать язык и подход к реализации.

## Решение
Выбран Python 3.10+ с использованием только стандартной библиотеки (pathlib, hashlib, subprocess, re).

## Обоснование (Trade-offs)
- **Плюсы:** Высокая читаемость, мощная стандартная библиотека, отсутствие внешних зависимостей (принцип Чистоты), легкая интеграция с GitHub Actions.
- **Минусы:** Медленнее компилируемых языков (но для сканера репозитория это некритично).
- **Альтернативы:** Node.js (отклонён из-за необходимости управления node_modules и package.json для простого скрипта), Bash (отклонён из-за сложности парсинга и поддержки).
